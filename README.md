# Shop App

A small multi-page e-commerce demo built with React and React Router, as a learning project to practice client-side routing and component structure.

## Live Demo

https://shop-app-one-indol.vercel.app/

## Features

- Product listing page
- Dynamic product detail page based on URL parameter
- Shopping cart page
- Persistent navigation bar across all pages
- Dark-themed UI

## Tech Stack

- React
- Vite
- React Router (react-router-dom)
- ESLint
- Deployed on Vercel

## Running Locally

```bash
git clone https://github.com/aida-hashemi/shop-app.git
cd shop-app
npm install
npm run dev
```

## What I Learned

- Setting up client-side routing with `react-router-dom`
- Reading dynamic URL parameters with `useParams`
- Structuring a multi-page React app with reusable components
- Fixing SPA routing issues on deployment (Vercel rewrites)
- Git workflow: feature branches, merging, and pushing to GitHub

# Shop App

A small multi-page e-commerce demo built with React and React Router, as a learning project to practice client-side routing and component structure.

## Live Demo

https://shop-app-one-indol.vercel.app/

## Features

- Product listing page
- Dynamic product detail page based on URL parameter
- Shopping cart page
- Persistent navigation bar across all pages
- Dark-themed UI

## Tech Stack

- React
- Vite
- React Router (react-router-dom)
- ESLint
- Deployed on Vercel
